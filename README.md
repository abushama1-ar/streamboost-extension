# StreamBoost ⚡ - مساعد المشاهدة والتصفح

## كيف تثبت الإضافة؟

1. افتح Chrome واكتب بالعنوان: `chrome://extensions`
2. فعّل **وضع المطوّر (Developer mode)** من الزاوية العلوية اليمين
3. اضغط **"تحميل غير مضغوط" (Load unpacked)**
4. اختر مجلد `streamboost` (هذا المجلد نفسه)
5. خلص! بتشوف أيقونة ⚡ بشريط الأدوات

## شو بتعمل الإضافة؟

### 🎬 متحكم الفيديو (يطلع تلقائياً تحت يمين أي فيديو)
- ⏪⏩ تخطي للأمام/خلف (10 ثواني افتراضياً)
- −/+ تغيير سرعة التشغيل (0.25x → 3x)
- 📺 صورة داخل صورة (Picture-in-Picture)
- 🔅🔆 تعديل سطوع الفيديو
- 🎯 وضع التركيز (يعتم باقي الصفحة)
- اختصار: **Shift + → / ←** للتقديم والتأخير

### 🔄 استئناف المشاهدة
بتتذكر آخر مكان وقفت فيه بأي فيديو وبأي موقع، وبتقترح عليك تكمل منه لما ترجع.

### 🛡️ حظر الإعلانات
- يحجب أشهر 25+ شبكة إعلانية معروفة (doubleclick, googlesyndication, popads, propellerads...)
- يوقف نوافذ popup/popunder المزعجة
- يخفي عناصر الإعلانات المنبثقة تلقائياً
- بيظهر عداد عدد العناصر المحظورة بكل صفحة (badge على الأيقونة)

### 🌙 إضافات تانية
- وضع ليلي إجباري على أي موقع
- وضع تركيز يعتم كل شي إلا الفيديو

## ملاحظة مهمة عن حظر الإعلانات
حظر الإعلانات هون قوي ويغطي أشهر الشبكات، بس مش بديل 100% عن uBlock Origin
الاحترافي اللي بيستخدم قوائم فلترة ضخمة (EasyList) بتتحدث يومياً من خوادم خارجية.
ممكن نضيف شبكات إعلانية أكتر إذا واجهتك مواقع معينة بتفلت من الحظر - خبرني وبزودلك القائمة.

## تخصيص الإعدادات
اضغط أيقونة ⚡ بشريط الأدوات لتشغيل/إيقاف أي ميزة، وتغيير سرعة التشغيل الافتراضية
ومدة التخطي.
